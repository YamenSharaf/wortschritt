# drafts — dump zone

Throw exercise ideas / examples in here. **No structure required.**

- Any format: JSON, a `.md` or `.txt` description, a screenshot `.png`, whatever's
  easiest. Rough is fine.
- One file or many, named anything. Don't organize it.
- Nothing here is loaded by the app (this folder is outside `content/`), so it
  can be as messy as you like.

When you want a format turned into a real feature, point me at what you dumped
and I'll generalize it into a Zod exercise `type` (in
`packages/shared/src/exercises.ts`) + a renderer, and the validated content
lands in `content/exercises/`.
